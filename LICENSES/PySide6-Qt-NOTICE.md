# PySide6 / Qt 运行时告知

POICollector v1.0.0 的 Windows 可执行文件使用 **PySide6 6.11.1** 与其 Qt 运行时组件。

PySide6 的 PyPI 元数据列出的开源许可证选项为 **LGPL-3.0-only OR GPL-2.0-only OR GPL-3.0-only**。本项目发行包按 LGPL-3.0 路径准备告知材料；完整的 LGPL-3.0 和 GPL-3.0 文本位于同一目录。

- PySide6 项目：https://doc.qt.io/qtforpython/
- PySide6 源码：https://code.qt.io/cgit/pyside/pyside-setup.git/
- Qt 许可说明：https://doc.qt.io/qtforpython-6/overviews/qtdoc-lgpl.html

本项目的 Python 源码可在同一 Release 的源码附件或 Git 仓库中获得。对单文件打包、替换/重链接等 LGPL 义务的满足方式，应在每次正式公开发行前结合当时的 PySide6/Qt 版本与打包产物重新核验；本说明不构成法律意见。
