# 更新日志

本项目遵循 [语义化版本](https://semver.org/lang/zh-CN/) 记录面向用户的变更。

## [1.0.1] - 2026-09-05（重建版，并入原计划的 v1.0.2）

### 修复

- **POI 分类编码表前导零**：内置分类表 503/915 条编码缺失前导零（如餐饮服务 `050000` 被存为 `50000`），勾选汽车服务/餐饮/购物/生活/体育休闲/医疗保健等 0 开头大类及其子类时采集必为 0 条。已全部补回，并新增 6 位编码与层级一致性回归测试。
- **大多边形采集失败**：顶点过多时 GET 请求 URL 超过服务端限制（实测 370 顶点返回 HTTP 413、空响应）。现自动改用包围盒矩形查询并在本地按原多边形边界过滤；按官方要求自动闭合非矩形多边形首尾坐标对。
- **网络与 Key 诊断增强**：区分网络错误 / HTTP 错误 / 响应解析错误并附响应片段；Key 无效（10001）独立提示并立即终止；采集 0 条时输出实际请求 URL 供浏览器核对。
- **多 Key 轮询**：首次请求使用第一把 Key（原先被跳过）。
- **分片子请求参数白名单**：city / citylimit / sortrule 等周边/关键字专有参数不再进入 polygon 子请求；探测进度定期播报、数据过密警告。

### 说明

- 本版本为 v1.0.1 重建版，包含 2026-09-01 发布的 v1.0.1 全部内容与原计划 v1.0.2 的诊断改进。已下载旧构建的用户请重新下载。

## [1.0.0] - 2026-08-13

### 首次公开准备版

- 提供周边、关键字、多边形和 POI ID 四种查询模式。
- 支持网格分片、断点续采、跨页去重及 ArcGIS 导入。
- 支持 CSV、Excel、GeoJSON、JSON 和 Shapefile 导出。
- 使用 PySide6 桌面界面，并提供 Windows 单文件 EXE 打包配置。
- 补充自动测试、持续集成、依赖锁定、维护文档和第三方许可说明。
